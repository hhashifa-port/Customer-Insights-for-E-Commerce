# Raw Project: **Working with SQL and Tableau**

This on-going project will analyze the characteristics of customers from a certain E-Commerce.

### Dataset description
The dataset used in this project is [Marketing Insights for E-Commerce](https://www.kaggle.com/datasets/rishikumarrajvansh/marketing-insights-for-e-commerce-company/data) obtained from Kaggle.

### Cleaning the datasets with SQL
There's no missing values nor duplicates data. Whereas, SQL used for data validation such as formatting, merged information from one to another database.
